# 種子畫廊 · seed-gallery

用文字或照片製作 AI 圖片、影片，也能和 AI 聊天、詢問文件內容。手機與電腦都能直接使用，不必安裝。

**[開啟種子畫廊](https://weiwei84530.github.io/seed-gallery/)**

## 如何開始

1. 準備自己的 [Runware API Key](https://runware.ai/)，在網站的「設定服務」中輸入。
2. 選擇製作圖片、製作影片或聊天問答，寫下想法，也可以上傳照片或文件。
3. 選擇想使用的 AI 模型，再送出。可同時選擇多個模型，比較不同結果。
4. 查看作品與回答，下載喜歡的圖片、影片，或到設定匯出備份。

還沒有 API Key？可以先選「稍後設定 API Key」逛逛介面，生成與聊天前再完成設定。Key 驗證成功後會記在目前瀏覽器，下次不必重新輸入。

也支援私下提供自動設定連結：在網站網址後加上 `#key=YOUR_API_KEY`（Key 應經過 URL encoding）。例如 `?costs=hidden#key=YOUR_API_KEY` 可同時讓首次使用的金額顯示預設關閉。網頁會讀取並立即移除網址中的 Key，再自動驗證，成功後保存在目前瀏覽器；若已有不同的 Key，會先詢問是否更換。僅支援 `#` fragment，不使用 query parameter 傳送 Key。原始連結包含完整憑證，取得連結的人可能使用該 Key 的額度；不要公開張貼或轉傳。

## 可以做什麼

- **製作圖片**：描述想要的畫面，或上傳照片進行修改。
- **製作影片**：用文字或一張起始照片生成短片，也能把已有圖片帶入新影片作品。
- **聊天問答**：讓不同 AI 回答同一個問題，支援照片、TXT、PDF 與 DOCX 附件。
- **給我一點靈感**：取得圖片或影片的描述建議，選擇後仍可修改，再自行決定是否生成。
- **保存與備份**：作品與對話保存在目前瀏覽器，可下載媒體，或匯出、還原 ZIP 備份。

也可以將網站加入手機主畫面。首次連網後，可離線開啟並查看已完整保存的作品；生成與聊天仍需要網路。iPhone 主畫面 App 與 Safari 的資料可能分開，切換前請先匯出備份。

## 費用與資料

- **API 使用會產生費用**，由 Runware 計費；多模型生成、重新回答與「給我一點靈感」也會計費。可在設定關閉「顯示餘額與費用」，但隱藏金額不會停止計費。
- **Key 只保存在目前瀏覽器**，可在設定更換或移除。請在信任的裝置使用，不要分享自己的 Key。
- **生成與聊天時**，描述、相關對話及照片或附件會傳送至 Runware 和必要的上游服務。網站作者不收集這些內容；服務商如何處理資料，請參考 [Runware 隱私政策](https://runware.ai/privacy)。
- **不同裝置不會自動同步**，即使用同一組 Key 也是如此。ZIP 備份包含作品、對話與附件，不包含 Key。
- **瀏覽器保存不能取代備份**。清除瀏覽器資料或儲存空間被回收，都可能遺失作品，請下載重要檔案並定期備份。

## 在自己的電腦安裝與執行

需要先安裝 Node.js 24（含 npm），並下載或 clone 此專案。在專案資料夾開啟終端機，執行：

```sh
npm ci
npm run dev
```

開啟終端機顯示的本機網址，即可使用。API Key 在網頁中輸入，不需要寫入程式或設定檔。

Windows PowerShell 若無法執行 `npm`，可改用 `npm.cmd`。

需要檢查程式或產生部署檔案時：

```sh
npm test
npm run build
```

## 部署到 GitHub Pages

1. Fork 此 repo，或將專案上傳到自己的 GitHub repo。
2. 在 repo 的 **Settings → Pages → Source** 選擇 **GitHub Actions**。
3. 將程式推送至 `main`，既有 workflow 會執行檢查、測試與建置，再部署網站。
4. 到 **Actions** 確認部署成功，並從 **Settings → Pages** 開啟網站網址。

部署不需要 API Key 或 Actions secrets；每位使用者在網頁中設定自己的 Key。請勿把 Key 放進 repo、公開網址或部署檔案。

若使用其他靜態網站空間，執行 `npm run build` 後，上傳產生的 `dist/` 資料夾內容即可。
